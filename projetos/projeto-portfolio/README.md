
# Projeto — Portfólio pessoal

## Descrição

Site desenvolvido para apresentar meu perfil, minhas habilidades
e meus projetos acadêmicos e pessoais.

## Objetivo

Praticar a criação de páginas web, organização de arquivos,
documentação e versionamento de código.

## Tecnologias

- HTML5
- CSS3
- Git
- GitHub

## Arquivos

- `index.html`: conteúdo e estrutura da página.
- `style.css`: aparência visual do site.

## Como executar

Abra o arquivo `index.html` em um navegador.

## Publicação

O endereço do site será adicionado após a configuração
do GitHub Pages.

## Aprendizados

Este projeto permite praticar a estrutura de uma página web,
o uso de CSS e a organização de um repositório.
