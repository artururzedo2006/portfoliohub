
# PortfolioHUB

## Sobre o projeto

O PortfolioHUB é um portfólio acadêmico e profissional desenvolvido
como parte do desafio do Bootcamp I.

O objetivo é organizar projetos acadêmicos e pessoais, apresentar
minhas habilidades e registrar minha evolução no desenvolvimento web.

## Objetivos

- Praticar HTML e CSS.
- Aprender versionamento com Git.
- Organizar projetos no GitHub.
- Publicar um site usando GitHub Pages.
- Compartilhar projetos em plataformas profissionais.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Estrutura do repositório

- `index.html`: página principal do portfólio.
- `style.css`: estilos visuais da página.
- `README.md`: documentação do projeto.
- `projetos/`: pasta destinada aos projetos acadêmicos e pessoais.
- `docs/`: pasta destinada a materiais complementares.
